# portafolio-funmar
Portafolio virtual de la Fundación Un Mar de Innovación, creado para promover la venta de artesanías y productos elaborados por mujeres emprendedoras. En el marco de la Formación Cultural desde la Igualdad de Género, impulsa el talento, preserva saberes tradicionales y fortalece la autonomía económica mediante herramientas digitales.
